# WavFry: Interactive Audio Demonstrations

Interactive demonstration website for **WavFry** (Noise-Robust Acoustic Phonation and Vocal Fry Detection).

🌐 **Live Demo**: [https://mumu233desu.github.io/wavfry-demo/](https://mumu233desu.github.io/wavfry-demo/)

---

## Highlights
- **Phonation Types**: Audio references for Modal, Creaky (Vocal Fry), and Breathy voice.
- **Degradation Matrix**: Audio and model detections across 18 real-world noise/reverberation conditions (15 dB, 5 dB, 0 dB).
- **Multi-Model Comparison**: Synchronized curves comparing WavFry (Ours), DeepFry, Kane et al., and Praat.
